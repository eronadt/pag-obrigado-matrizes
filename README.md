# Página de Obrigado - Acervo de 25.000 Matrizes de Bordado

Página de pós-venda / obrigado criada para entrega imediata do acervo de matrizes de bordado e direcionamento de suporte.

## 🚀 Tecnologias Utilizadas
- HTML5 semântico
- CSS3 moderno (Variáveis CSS, Backdrop Blur, Gradientes e Animações)
- Ícones SVG vetoriais embutidos
- Tipografia: *Plus Jakarta Sans* via Google Fonts

## 🔗 Links e Recursos
- **Acesso ao Acervo:** Google Drive
- **Suporte:** WhatsApp e E-mail integrados
- **Design:** Responsivo (Desktop, Tablet e Mobile)
